{{ api_signature(value="jess.l10n: { bundle, bundles, locales, setLocales, addDirectory, reload, generation }") }}

Text for people comes from here, not from string literals. A script asks for a bundle once and calls it for each message with the variables the pattern names; locale fallback, plural rules, and number formatting are the library's. The module is also `require("@jess/l10n")`. The model, the file layout, and the grammar are in [Localization](@/docs/contributing/localization.md).

```luau
--!strict
local l10n = require('@jess/l10n')
l10n.addDirectory('my-package/l10n')
l10n.reload()
l10n.setLocales { 'pl-PL', 'en' }

local common = l10n.bundle 'common'
print(common('hello', { name = 'Fargoth' })) -- Cześć, Fargoth!
print(common('file_count', { count = 5 })) -- 5 plików
```

{% usage_note(title="Two capabilities") %}
`bundle`, `bundles`, `locales`, and `generation`, and calling a bundle (`format`, `has`), read text: `l10n.read`. `setLocales`, `addDirectory`, and `reload` change what every script sees: `l10n.configure`. Under a script domain every call checks its capability, and a context or worker without it gets `capability 'l10n.read' denied to domain#1 gen#1 context#2`. Outside any domain (a plain `jess run`) nothing holds authority and every call succeeds.
{% end %}

{% usage_note(title="Whose registry") %}
Under a host ([Application Kernel](@/docs/contributing/application-kernel.md)) every call reaches the application's registry: the one the host configured, shared by the main runtime and by every worker spawned with `shareServices = true`. A locale change there is broadcast to every context as `{ event = 'l10n.changed', generation, locales }`. Anywhere else the runtime keeps a registry of its own, and the API is the same.
{% end %}

## jess.l10n.bundle

{{ api_signature(value="jess.l10n.bundle(name: string, fallbackLocale: string?) -> L10nBundle") }}

The bundle named `name`, declared now if no provider offered it. `fallbackLocale` (default `en`) is the locale tried after every preferred one and its parents; passing it again changes it.

- **Parameters:** `name`: segments of letters, digits, `_`, and `-`, joined by `.` (`common`, `jess.editor`). `fallbackLocale`: a BCP 47 tag.
- **Errors:** `'bad name' isn't a bundle name: use letters, digits, '_', and '-', in segments separated by '.'`; `'english' isn't a BCP 47 locale: The given language subtag is invalid`.

## jess.l10n.bundles

{{ api_signature(value="jess.l10n.bundles() -> { string }") }}

Every bundle: the ones providers offered at the last reload and the ones scripts asked for.

## jess.l10n.locales

{{ api_signature(value="jess.l10n.locales() -> { string }") }}

The preferred locales, canonically spelled, as they were set. Empty until `setLocales` runs: then only each bundle's fallback locale is used.

## jess.l10n.setLocales

{{ api_signature(value="jess.l10n.setLocales(locales: string | { string }) -> number") }}

Sets the preferred locales, most wanted first, and returns the new generation. A message is looked up in each locale and then its parents (`pt-BR`, then `pt`) before the next locale, then in the bundle's fallback. Every bundle resolves again; nothing recompiles.

- **Errors:** `'english' isn't a BCP 47 locale: ...`; `locales must be a list of strings, not number`.

```luau
--!strict
local common = jess.l10n.bundle 'common'
jess.l10n.setLocales 'de-AT'
print(common('hello', { name = 'Fargoth' })) -- Hallo, Fargoth! (from de.toml)
```

## jess.l10n.addDirectory

{{ api_signature(value="jess.l10n.addDirectory(path: string, name: string?) -> ()") }}

Adds a folder of `<bundle>/<locale>.toml` files as a provider, named `name` (default: the path) in diagnostics and provenance. Providers added later override earlier ones, message by message. Nothing is read until the next `reload`.

## jess.l10n.reload

{{ api_signature(value="jess.l10n.reload() -> { L10nDiagnostic }") }}

Reads every provider again, compiles every pattern of every locale, and swaps in each bundle that loaded without an error. A bundle with an error keeps its last good text, so a broken edit never blanks the application. Returns what was wrong; an empty list is a clean reload.

```luau
--!strict
for _, problem in jess.l10n.reload() do
  print(`{problem.severity}[{problem.kind}] {problem.path}:{problem.line}: {problem.detail}`)
end
```

### L10nDiagnostic

{{ api_signature(value="type L10nDiagnostic = { severity: 'info' | 'warning' | 'error', kind: string, detail: string, generation: number, provider: string?, path: string?, line: number?, column: number?, bundle: string?, locale: string?, message: string? }") }}

One problem. `kind` is a code: `pattern-parse-failure`, `bundle-parse-failure`, `duplicate-message`, `provider-collision`, `invalid-locale`, `invalid-bundle-name`, `provider-failure`, or `empty-bundle` (a warning: a bundle nobody has files for). `line` and `column` point at the message id, or, for a pattern that doesn't compile, at the place in the pattern.

## jess.l10n.generation

{{ api_signature(value="jess.l10n.generation() -> number") }}

The generation: it rises whenever a reload swaps a bundle in or the preferred locales change, which is whenever text a script cached may be stale.

## L10nBundle

A bundle handle. Call it, or call `format` on it; `tostring(bundle)` is `L10nBundle(common)`.

### bundle(id, variables)

{{ api_signature(value="bundle(id: string, variables: L10nVariables?) -> string") }}

The message `id` in the first locale of the chain that defines it, with `variables` filled in. The plural and number rules are those of the locale the text came from.

- **Parameters:** `variables`: a table of the names the pattern uses to strings, numbers, or booleans (`{ count = 3, name = 'Fargoth' }`). A plural or `number` argument needs a number; a `select` needs a string or boolean; a plain `{name}` takes any of the three.
- **Errors:** `bundle 'common' has no message 'missing' in pl-PL, pl, en`; `bundle 'common', message 'hello' (en): argument 'name' is missing`; `... argument 'count' must be a number, not a string`; `variable 'name' of message 'hello' in bundle 'common' must be a string, number, or boolean, not table`. A missing message is never an empty string and never the id passed off as text.

```luau
--!strict
local common = jess.l10n.bundle 'common'
print(common('file_count', { count = 0 })) -- No files
print(common('file_count', { count = 1 })) -- 1 file
print(common('file_count', { count = 1234 })) -- 1,234 files
print(common('mode_label', { mode = 'edit' })) -- Editing
```

### bundle:format

{{ api_signature(value="bundle:format(id: string, variables: L10nVariables?) -> string") }}

The same as calling the bundle, for code that prefers a method.

### bundle:has

{{ api_signature(value="bundle:has(id: string) -> boolean") }}

Whether some locale in the chain defines `id`. Formatting a message that isn't there is an error; this is the question to ask first when a message is optional.

### bundle.name

{{ api_signature(value="bundle.name: string") }}

The bundle's name.

### L10nVariables

{{ api_signature(value="type L10nVariables = { [string]: string | number | boolean }") }}

The variables a message takes, by the names its pattern uses. Tables, functions, and userdata are errors naming the variable, the message, and the bundle: localization formats semantic values, so a script reduces an object to one first.
