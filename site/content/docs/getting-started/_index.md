Install jess, run a few commands against your own load order, then learn the two things every command shares: how it finds the files you name, and what it prints.

1. [Install](@/docs/getting-started/install.md) the binary.
2. Run the [First Commands](@/docs/getting-started/first-commands.md). Only `jess init` writes anything.
3. Read [Paths, Configs, and Encodings](@/docs/getting-started/openmw-config.md): files by path, masters beside the plugin, and load orders in scripts.
4. Skim [Output Formats](@/docs/getting-started/output-formats.md): YAML, JSON, backups, and exit codes.

Depending on where you're coming from:

- **No OpenMW?** [Using jess without OpenMW](@/docs/getting-started/without-openmw.md), for Morrowind.exe and MGE XE setups.
- **Used tes3cmd?** [Coming from tes3cmd](@/docs/getting-started/coming-from-tes3cmd.md) maps every command.
- **Going to script?** [Editor Setup](@/docs/getting-started/editor-setup.md) gets you types and completion in VS Code, Neovim, Zed, or Helix.
