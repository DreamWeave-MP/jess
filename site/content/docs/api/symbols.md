This index is generated from the same type surface as `jess luau-types`. Follow a symbol to its reference page for behavior, capabilities, failures, and examples. A signature without a type or return annotation leaves that part to Luau's type inference. The [JSON catalog](../../../api-catalog.json) contains the same entries for tools.

The signatures describe the runtime used for this documentation build. Generate types with your own Jess installation when working against a different version.

For a direct link to a symbol, the anchor is `symbol-` followed by the lowercase hexadecimal UTF-8 bytes of its catalog `name`. The catalog's `symbolIndex` and `anchorEncoding` fields identify this page and encoding. Each entry also links to the handwritten reference recorded in its `page` and `anchor` fields.
